# Detection research backlog

These are research hypotheses collected on 2026-09-23. They are not production rules or demonstrated agent signatures. The current implementation includes scored activity labels, account-scoped operator attribution, configurable scoring, and optional aggregate movement/timing features. See [agent classification](AGENT-CLASSIFICATION.md) and the [benchmark comparison](EXTERNAL-BENCHMARKS.md). Runtime probes, focus-based screenshot inference and hidden decoys remain research ideas, not enabled rules.

| Idea                                        | Experiment before adoption                                                                                                 | Important controls                                                                                                                                       |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CDP/runtime timing and automation globals   | Compare instrumented and uninstrumented browsers across versions and devices. Measure added value beyond existing signals. | DevTools, extensions, CPU load, privacy protections, accessibility software. CDP is not required for every agent.                                        |
| Permission-state inconsistencies            | Test documented read-only permission states with known configurations.                                                     | Browser differences, enterprise policy, denied permissions, private browsing. Never request permissions solely to fingerprint.                           |
| Cursor jumps and target alignment           | Evaluate aggregate, locally computed movement features on independently labeled sessions.                                  | Coalesced events, low sample rates, touch, keyboard navigation, remote desktops and assistive input. A missing movement path is not proof of automation. |
| Interaction timing distributions            | Compare bounded timing summaries against the current mean/variance baseline.                                               | Task, sample count, observation duration, paste, password managers, device and accessibility controls. No actual keys or raw event trails.               |
| Focus/visibility changes around screenshots | Test whether capture causes any reproducible observable effect for each supported environment.                             | Screen recording, window switching, conferencing, browser throttling. Screenshot capture does not generally require a focus change.                      |
| Task traversal and repeated workflows       | Learn associations from server-owned operation categories and transitions.                                                 | Human experts, SPA prefetch, polling, retries and repetitive legitimate work. Our page cannot generally observe an agent's private telemetry endpoints.  |
| Hidden interaction decoys                   | Separate optional application experiment, if ever adopted. Measure false positives and accessibility impact first.         | Focus navigation, screen readers, password managers, prefetch and testing tools. No automatic blocking and no deceptive security-sensitive actions.      |

Promotion requires an independently labeled holdout, measured incremental benefit, false-positive analysis, calibration, a privacy review of actual collected fields, and a versioned rollback. Predictions must never become their own ground-truth labels. Timing/global-name heuristics must be tested against unseen browser and agent versions.

None of these notes enables raw mouse coordinate arrays, individual keystroke timing trails, hidden probes, anti-fingerprinting bypasses, or page mutations. Any new collector needs a concrete, reviewed data contract and a controlled experiment first.
