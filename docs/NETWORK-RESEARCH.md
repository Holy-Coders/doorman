# Reviewed evidence for the learning pilot

This catalog records why a design choice exists and the executable regression covering it. Research updates enter normal code review. The service does not execute instructions from papers, websites, model answers or contributed labels, and never rewrites the repository automatically.

Reviewed 2026-09-23:

| Primary source                                                                                   | Finding used here                                                                                                                      | Implementation / regression                                                                                                                   |
| ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| [Cloudflare bot scores](https://developers.cloudflare.com/bots/concepts/bot-score/)              | Commercial bot assessment combines multiple detection sources and session characteristics; missing signals can create false positives. | Missing features never satisfy predicates; network-discovery tests include sparse APIs and corroborating feature groups.                      |
| [scikit-learn cross-validation](https://scikit-learn.org/stable/modules/cross_validation.html)   | Grouped and time-ordered evaluation address different leakage risks.                                                                   | Discovery excludes held-out applications and future feedback from training; tests invert held-out labels without changing learned predicates. |
| [scikit-learn probability calibration](https://scikit-learn.org/stable/modules/calibration.html) | A model score and empirically calibrated event probability are different.                                                              | Reports expose observed metrics; private pattern precision is never an authenticated identity or a calibrated per-request confidence.         |
| [TypeSafe API](https://docs.typesafe.ai/api)                                                     | Typed questions evaluate supplied state.                                                                                               | Shared service uses `state` and `noul` questions; mocked transport conformance rejects malformed answers. No automatic weight-training claim. |
| [Cloudflare Jev](https://developers.cloudflare.com/ai/models/typesafe/jev/)                      | Workers AI invokes `typesafe/jev` with the same structured evaluation form.                                                            | Workers AI adapter contract test and deployment dry run.                                                                                      |
