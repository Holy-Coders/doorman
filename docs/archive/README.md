# Historical research and advanced APIs

These records are retained for contributors and for interpreting old experiments. They are not part of the current product setup, public navigation, search index or installation requirements. Code for some advanced modules remains in the repository; that does not make it part of the recommended integration.

Use the [current docs](https://doorman.holycoders.io/docs/introduction/) for `createDoorman`, native Phoenix, analytics and optional Jev scoring. Normal setup does not require model training, a shared learning service, an operator directory or manual migrations.
